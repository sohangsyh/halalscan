HOW IT WORKS

      
    

    
    
      
  1. Choose "Ingredient List" or "Image" mode, then point your camera or upload a photo.
    2. 
      
  2. In Ingredient List mode, the text is read automatically — no language selection needed. In Image mode, the photo's visual content is identified instead.
    3. 
      
  3. By default this runs fully on-device and free (Tesseract.js for text, MobileNet for images). If you add a Gemini API key in Settings, the app uses Gemini instead — far more accurate OCR with automatic language detection and English translation for matching, and Gemini-based photo identification (the closest available equivalent to Google Lens, which has no public API).
    4. 
      
  4. Results are checked against a Halal / Haram / Mashbooh database covering common translations, E-numbers, derivatives, and visual cues.
    5. 
      
  5. The photo on screen tints green, red, or amber with an instant verdict.
    6. 
    

    
This tool provides guidance only and does not replace official Halal certification bodies. When in doubt, contact the manufacturer.

      How to get an API key
      
    
        
  1. Open Google AI Studio (aistudio.google.com) and sign in.
    2. 
        
  2. Go to "Get API key" and create a new key (this also enables the Gemini API on a Google Cloud project for you).
    3. 
        
  3. Copy the key — it should start with AIza.
    4. 
        
  4. Paste the key above. It is used only in this browser, sent directly to Google, and is not saved anywhere — you'll need to re-enter it if you reload the page.
    5. 
      

      
Gemini has a free tier with rate limits (requests per minute/day); heavier use may require enabling billing. Check current limits and pricing at ai.google.dev before relying on this for heavy use.
